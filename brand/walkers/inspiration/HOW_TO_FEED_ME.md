# How to feed Pixel so walkers get *exciting*

Usable = silhouette reads on a planet at ~32–64px.  
**Exciting** = you want to click them, assign them, show a friend.

## What to send (any mix)

### 1. One sentence + vibe tags (fastest)
```
Hero-lane traveler, DQ8×SoA, slight chibi, mustard vest, orange bandana,
warm sunset travelogue, not VTuber, not grimdark.
Tags: hopeful, wind, journey, SoA-blue-sky
```

### 2. References (best)
- 1–3 images: style OR costume OR species (not “copy this character”)
- Circle what matters: “head scale like THIS”, “cloak energy like THAT”
- Drop files in `brand/walkers/refs/` or paste paths here

### 3. Species brief
```
Species: [human / slime / birdfolk / catfolk / robot / ???]
Body: [biped / quadruped / float]
Signature: [one silhouette read — e.g. “big scarf”, “shell backpack”, “halo ears”]
Forbidden: [list]
```

### 4. Motion intent
```
Walk: [brisk / bounce / stomp / glide]
Idle: [shift weight / breathe / look around]
Planet feel: [tiny god-game / JRPG overworld / toy diorama]
```

### 5. Emotional north star (the “exciting” dial)
One line only, e.g.:
- “Skies of Arcadia crew stepping off the little yellow ship”
- “Studio Ghibli kid on a big hill, pixel distance”
- “TE pocket device mascot but adventure not corporate”

## What does *not* help
- “Make it cool” with no noun
- 40 conflicting refs
- Photo-real skin / Unreal / VTuber eyes (AxisLock forbids)
- Full screenplays before one silhouette works
