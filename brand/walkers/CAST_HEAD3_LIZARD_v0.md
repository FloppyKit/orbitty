# Head 3 — Lizard / dinosaur?

## Recommendation: **skip in first-party v0 ship**

### Why skip (for now)
| Factor | |
|--------|--|
| **You already have the system** | Head A human + Head B furry + **mouth swaps** (cat/dog) + eyes/hair/hats |
| **Diminishing returns** | 3rd head = another SoT to light, chin, eyes anchor, hair collide, outline — not “one more PNG” |
| **Lizard needs different topology** | Snout length, no external ear (or different), brow ridge — breaks furry ear assumptions |
| **9-month trap** | First-party dino set invites armor frills, teeth variants, seasons… |
| **UGC fits better** | Pack schema already allows community `heads/` — lizard as **season pack** or maker pack |

- Someone in community ships a lizard pack you want to bless, **or**

- Mouth slot: closed smile / toothy grin only  
- No frills armor v0  
- Same pink-mauve facet language so it sits in the doll family
