# src/lib

Page components live here, not in a child folder. `src/routes/+page.svelte` mounts them.

The desks are `RailPage.svelte`, `KanbanPage.svelte`, `StarsPage.svelte`, `CompanionPage.svelte`, and `SettingsPage.svelte`. Settings tabs are `SettingsAppearance.svelte`, `SettingsPacks.svelte`, and `SettingsPlans.svelte`.

Folders: `board/`, `companion/`, `rail/`, `stars/`.
