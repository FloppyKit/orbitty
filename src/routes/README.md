# routes

The one route.

`+page.svelte` reads the window label and mounts `RailPage`, `KanbanPage`, `StarsPage`, `CompanionPage`, `SettingsPage`, and the other label pages (`SkyPage`, `YardWarnPage`, `NextCard`, `CheatSheet`, `LinkPreviewPopover`). `+layout.ts` is the layout.

There is no second route.
