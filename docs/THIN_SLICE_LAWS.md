## Non-negotiable

1. **Explicit claim only** — window/tab becomes a sprite only after human claim/assign to a named project planet.
2. **Unmapped = zero sprites** — no auto-mapping every open window into a pet. Rail may list unmapped rows; habitat stays empty of ghosts.
3. **Zombie aging** — untouched claimed work fades/parks/culls after N days (N tuned later). Graveyards kill magic.
4. **Points only on explicit goal-aligned complete** — no dwell-time, no self-report farming. Hard caps. Clinical-first / Master Deck heavier weight. Non-shaming.
5. **No harness rebuild inside sprite engine** — thin launchers into existing Hermes / Goose / Cursor only. No hosted LLM loop in LiveSprite.
6. **Identity fence** — runtime consolidator feeding LifeRPG ≠ multi-agent OS.
7. **Not EHR** — titles/metadata only. No PHI in sprites, planets, graph, or points.
8. **FKT forever separate** — no signer/USB merge into this tree.

## Forbidden until thin-slice is daily-used

Narratives, multi-guardians, auto-scoring, fancy planet physics, deep zoom/decor/music, secondary agents in-engine, RGL dependency for first loop.

## S0 note

This scaffold does **not** implement claim/AX/sprites yet. Laws bind all future S1+ work.
