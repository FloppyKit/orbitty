# ACCEPTANCE — GO-ORBITTY-HOST-FIT

Dogfood: tray Quit → only `~/Applications/Orbitty.app` → AX re-grant if asked.

## Must

- On a landscape display, dest Launchpad: companion grows **wide** (~1080×620). Well is still left Launchpad / right Head.
- On a portrait display, dest Launchpad: companion grows **tall** (~620×1080), not a wide slab. Well still usable.
- Dismiss dest: idle size comes back (the stashed 520×780 or whatever you had), not the host frame.
- Launchpad ↔ STARS while hosted does not restore idle; host frame stays (re-fit ok).
- Idle Expand / Full/Head / overlay still as HOST-VIEW.

## Must not

- Idle auto-resizing when you just drag the spirit between monitors (no well)
- Host size persisted as the new idle
- Moved-during-drag persist
- CompanionPage edits / HOST-VIEW regression / `tauri dev` / stamp
